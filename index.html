Culinary Blog Website

Tech stack:

Astro Tailwind CSS TypeScript Markdown

Visit the website .

Link to github repo .

This SSR (server-side rendered) project demonstrates a content-driven culinary platform. The homepage renders six articles, each featuring clickable tags and a search bar for content filtering. A dedicated detail page dynamically displays the recipe content associated with the selected tag. Placeholder images are currently used for demonstration purposes.

Data Collection App

Tech stack:

PHP Laravel Tailwind CSS Flowbite JavaScript MySQL

Visit the website .

Link to github repo .

A Laravel-based data collection application using form-driven workflows. The backend is implemented in PHP with Laravel, following MVC principles, while the frontend is styled using Tailwind CSS. Form submissions are validated server-side and persisted in a MySQL database. Authentication is handled via a custom login system based on access codes and predefined credentials, with user provisioning managed by an administrator.

Movie Finder App.

Tech stack:

JavaScript HTML CSS

Visit the website .

Link to github repo .

A client-side movie search application built with HTML, CSS, and vanilla JavaScript, developed as part of a course-based project. The app implements client-side routing, search state management, and dynamic movie detail rendering using the TMDB API (free tier).

FenoBarbital Dose Calc for Dogs | ToDos-list | WHO-region finder.

Tech stack:

JavaScript HTML CSS

Visit FB-calc here, Daily ToDos here and WHO regions finder here.

These are client-side applications built with HTML, CSS, and vanilla JavaScript. DoseCalc is a lightweight calculator that implements a specific formula for dosage computation.The ToDo List application uses the browser's Local Storage API to persist tasks across sessions and provides calendar-based task access. WHO Regions Finder is a lightweight client-side utility which performs an instant lookup from a local dataset to map a user-provided country name to its corresponding WHO region, with no backend or external API calls.

Cryptocurrency Tracker

Tech stack:

React HTML CSS

Visit the website .

Link to github repo .

This lightweight React application was developed as part of a course-based project and integrates the CoinGecko API to retrieve cryptocurrency data. Data fetching is handled via the useEffect hook, which triggers HTTP requests and updates the component state to render dynamic content in the UI.
