# My Presentation site

A static single-page website built with HTML, CSS, and JavaScript, featuring modals, scrolling, and a contact form powered by Formspree.
This site is my first portfolio site.

---

## Live Demo

[Live site here](https://rcd-portfolio.netlify.app/)

## Tech Stack

- HTML5
- CSS3
- SCSS (SASS)
- JavaScript (ES6+, Fetch API)
- Bootstrap 5.3+
- Formspree

---

## Features

- Responsive single-page layout
- Smooth scrolling navigation
- Scroll to-top functionality
- Bootstrap modals and carousel components
- Contact form with email delivery via Formspree
- Client-side form feedback with success and error messages
- Clean and accessible UI
- Mobile-friendly design

---

## Getting Started (Local Setup)

### Instal dependencies (npm or pnpm)

```
npm install
```

- Development (watch mode)

```
npm run sass:watch
```

- Production build:

```
npm run sass:build
```

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or pnpm

### Installation

```bash
npm install
```

### Development

```bash
npm run sass:watch
```

### Build

```bash
npm run sass:build
```

---

## Notes

- This is a static website with no backend or database.
- JavaScript is used only for client-side interactions.
- The contact form is handled externally via Formspree.
- Asynchronous form submission implemented using the Fetch API with async/await.
- Designed to present my junior developer portfolio.
